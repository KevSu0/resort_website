# Admin CMS Quick Start Guide

## First-Time Setup

1. **Navigate to Admin Panel**
   - Go to `http://localhost:5176/admin/login`
   - You'll see the first-time setup wizard

2. **Create Admin Account**
   - Enter your full name
   - Use your email address
   - Create a strong password (8+ characters)
   - Confirm password

3. **Setup Complete**
   - Your account is created
   - You're redirected to login
   - Use your new credentials to sign in

## Daily Operations

### Dashboard Overview
- **Content Stats**: See how many properties, rooms, etc.
- **Recent Enquiries**: Latest guest enquiries
- **Quick Actions**: Common tasks
- **System Status**: Storage usage and health

### Managing Properties

1. **Add New Property**
   - Click "Properties" in sidebar
   - Click "New Property"
   - Fill in basic information
   - Upload hero image (2000×1333px)
   - Add gallery images
   - Select amenities
   - Configure SEO settings
   - Save

2. **Edit Existing Property**
   - Go to Properties list
   - Click "Edit" on property
   - Make changes
   - Save

### Managing Media

1. **Upload Images**
   - Go to Media Library
   - Click "Upload Media"
   - Select files or drag & drop
   - Add alt text
   - Upload

2. **Use Media in Content**
   - While editing any content
   - Click "Select Image" button
   - Choose from uploaded media
   - Media usage is tracked automatically

### Handling Enquiries

1. **New Enquiry Alert**
   - Dashboard shows new enquiries
   - Email notifications (if configured)

2. **Process Enquiry**
   - Click on enquiry to view details
   - Update status as you progress
   - Add notes for each interaction
   - Use quick actions to email/call

3. **Enquiry Status Flow**
   - New → Contacted → Quoted → Confirmed/Cancelled

### Publishing Content

1. **Draft Mode**
   - All changes start in draft
   - Safe to experiment
   - Not visible to visitors

2. **Publish Changes**
   - Go to Dashboard
   - Click "Publish Changes"
   - Add a version label
   - Content goes live

### Backup & Restore

1. **Create Backup**
   - Go to Export/Import
   - Select what to include
   - Click "Export Data"
   - Save ZIP file

2. **Restore from Backup**
   - Go to Export/Import
   - Upload backup ZIP
   - Review changes (dry run)
   - Apply changes

## Tips & Best Practices

### Images
- Compress images before upload
- Use descriptive filenames
- Always add alt text
- Hero images should be landscape (3:2 ratio)

### Content
- Use consistent formatting
- Fill all required fields
- Preview before publishing
- Keep descriptions concise but informative

### Enquiries
- Respond within 24 hours
- Update status regularly
- Document all communications
- Track conversion rates

### Security
- Use strong, unique passwords
- Don't share login credentials
- Log out when done
- Keep backups secure

## Common Tasks

### Adding a New Room Type
1. Go to Properties → Edit Property
2. Click "Add Room"
3. Fill room details
4. Set pricing
5. Add images
6. Save

### Creating a Special Offer
1. Go to Offers
2. Click "New Offer"
3. Set offer type (% or fixed)
4. Set validity period
5. Configure usage limits
6. Save

### Updating Contact Information
1. Go to Settings
2. Update contact details
3. Save changes
4. Publish to live site

### Checking Enquiry Statistics
1. Go to Enquiries
2. View statistics cards
3. Filter by date range
4. Export reports if needed

## Troubleshooting

### Login Issues
- Clear browser cache
- Verify correct email/password
- Check browser console for errors

### Image Upload Fails
- Check file size (max 1.5MB for hero)
- Verify image dimensions
- Try different browser

### Content Not Saving
- Check all required fields
- Look for error messages
- Try refreshing page

### Slow Performance
- Clear unused media
- Archive old enquiries
- Check browser storage

## Keyboard Shortcuts

- `Ctrl/Cmd + S`: Save current form
- `Ctrl/Cmd + Z`: Undo (where supported)
- `Esc`: Close modal/cancel
